# Сайт Анны Соколовой — askannasklv.github.io

Статический сайт для GitHub Pages: одна страница под позицию бизнес-аналитика (о себе, навыки, опыт, образование), EN/RU.

## Состав

| Файл | Что это |
|---|---|
| `index.html` | Главная страница (вся вёрстка, стили и скрипт внутри) |
| `404.html` | Страница «яблоко укатилось» для несуществующих адресов |
| `fonts/` | Шрифты Golos Text и IBM Plex Sans (латиница + кириллица), без загрузки с Google |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Иконка-яблоко во вкладке и на экране телефона |
| `og-cover.png` | Обложка 1200×630 для превью ссылки в Telegram, hh, почте |
| `cv/Sokolova_CV_EN.pdf`, `cv/Sokolova_CV_RU.pdf` | Резюме для скачивания (версия для сайта: компания обезличена, без телефона) |
| `robots.txt` | Разрешает индексацию поисковикам |
| `.nojekyll` | Говорит GitHub Pages отдавать файлы как есть |

## Первая публикация (один раз)

1. github.com → **New repository**.
2. Repository name: **`askannasklv.github.io`** (ровно так — тогда сайт будет по этому адресу).
3. Visibility: **Public** (на бесплатном тарифе Pages работает только с публичными репозиториями).
4. Галочки «Add a README» и прочие — **не ставить**, репозиторий должен быть пустым.
5. Create repository.
6. Settings → Pages → Build and deployment: Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)** → Save.
7. Через 1–2 минуты сайт открывается по адресу https://askannasklv.github.io

## Как обновлять

- Через браузер: открыть репозиторий → нужный файл → значок карандаша → правка → **Commit changes**. Или **Add file → Upload files** и перетащить новые версии файлов.
- Сайт обновляется сам через 1–2 минуты после коммита. Если в браузере старая версия — обновить страницу с Shift.

## Проверка превью ссылки

После публикации отправить ссылку себе в Telegram — должна появиться обложка с горами и именем. Если Telegram показывает старое превью, отправить ссылку боту @WebpageBot и нажать обновление.

## Если позже понадобится свой домен

1. Купить домен (например, askannasklv.ru у российского регистратора).
2. В репозитории создать файл `CNAME` с одной строкой: `askannasklv.ru`.
3. У регистратора в DNS добавить четыре A-записи для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`, и CNAME-запись `www` → `askannasklv.github.io`.
4. Settings → Pages → Custom domain → ввести домен → дождаться проверки → включить **Enforce HTTPS**.
5. В `index.html` заменить `https://askannasklv.github.io/` на новый адрес в строках `canonical`, `og:url`, `og:image`.
